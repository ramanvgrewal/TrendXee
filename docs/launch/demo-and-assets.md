## 35-second demo storyboard

| Time | Screen | Caption |
| --- | --- | --- |
| 0–4s | Homepage with a current daily board | Find your next fit. Meet a smaller label. |
| 4–9s | Open Jeans; use the Filters button | Start with a lane. Narrow it to your style. |
| 9–15s | Open an actual product; change gallery image | See the piece, not just a thumbnail. |
| 15–25s | Pair up with; show a complement and one swap | Build around it with pieces from other lanes. |
| 25–30s | Retailer button; avoid placing an order | Shop directly with the retailer. |
| 30–35s | Return to the board; short URL on screen | Try TrendXee. Tell us what you'd change. |

Use actual production data, real interactions and captions legible on a phone. Hide personal account details and browser bookmarks. Record without narration if recording conditions are poor; add captions rather than synthetic testimonials.

No video has been recorded in this task. This is a shot list.

## Product gallery brief

1. Discovery: the homepage and “Discover Indian indie fashion.”
2. Lanes and filters: one category view, with a short explanation of what can be filtered.
3. Product detail: full gallery and clear retailer destination.
4. Pair up with: show the source item and two complementary roles, using real selections.
5. Mobile: one readable phone view; avoid a tiny complete desktop page inside a frame.

Confirm required image dimensions in each platform's current upload form. Do not pad a screenshot with unsupported claims such as verified quality, biggest catalogue or guaranteed best price.
